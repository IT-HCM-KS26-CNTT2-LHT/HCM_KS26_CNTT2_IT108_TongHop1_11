# SmartCampus

Ứng dụng di động giúp sinh viên **PTIT** *tra cứu lịch học*, phòng trống và nhận thông báo mới nhất từ nhà trường.

![Logo SmartCampus](https://example.com/smartcampus-logo.png)

## Tính năng đã hoàn thành

- Tra cứu lịch học
  - Tra cứu theo mã sinh viên
- Xem danh sách phòng trống
  - Xem theo tòa nhà

Trang chủ CLB: [CLB Lập trình](https://clblaptrinh.ptit.edu.vn)

> **Cảnh báo:** Dự án đang trong giai đoạn phát triển, chưa dùng cho mục đích chính thức.

---

## Cài đặt

```bash
git clone https://github.com/clb-lap-trinh/smartcampus.git
npm install
npm start
```

## Tiến độ phát triển

- [x] Tra cứu lịch học theo mã sinh viên
- [x] Xem danh sách phòng trống theo tòa nhà
- [ ] Thông báo đẩy (push notification)
- [ ] Đăng nhập bằng tài khoản trường
